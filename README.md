## 🛠️ Teknologi yang Digunakan (Tech Stack)

Website ini dibangun murni menggunakan teknologi web standar tanpa framework JS/CSS tambahan untuk memastikan performa yang cepat dan kode yang bersih:

* **HTML5:** Struktur semantik, aksesibilitas (a11y), dan optimasi SEO.
* **CSS3:** Penggunaan *CSS Variables*, Flexbox, dan CSS Grid untuk tampilan responsif.
* **JavaScript:** Vanilla JS (ES6+) untuk navigasi, efek sticky header, menu mobile, dan validasi formulir.
* **Ikon:** [Lucide Icons](https://lucide.dev/) (via CDN).
* **Typography:** Google Fonts ([Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)).

## 🚀 Cara Menjalankan Proyek Secara Lokal

Karena proyek ini berbasis web statis (Vanilla HTML/CSS/JS), Anda tidak memerlukan proses kompilasi atau install `npm dependencies`.

1. **Clone atau Unduh Repositori**:
   ```bash
   git clone https://github.com/RayLunaris/Portofolio.git
   cd Portofolio
   ```

2. **Buka File `index.html`**:
   - Langsung klik ganda file `index.html` untuk membuka di web browser favorit Anda (Chrome, Edge, Firefox, Safari).
   - Atau gunakan ekstensi **Live Server** di VS Code untuk preview real-time.
